Cadence Music Server – Database Schema

tracks

Column Type Purpose
id INTEGER PRIMARY KEY Auto-incrementing internal ID
path TEXT UNIQUE NOT NULL Absolute or relative path to the audio file
title TEXT Track title (from tags or Qobuz)
artist TEXT Primary artist name
artist_id INTEGER Qobuz artist ID (when known)
album TEXT Album title
track_number INTEGER Track number on the album
duration REAL Duration in seconds
format TEXT File format (flac, wav, mp3, …)
stream_url TEXT Local streaming URL for the file
genre TEXT Genre name (from album tags or Qobuz album)
updated_at TEXT ISO timestamp of the last upsert

genres

Column Type Purpose
id INTEGER PRIMARY KEY Auto-incrementing genre ID
name TEXT UNIQUE NOT NULL Unique genre name

track_genres

Column Type Purpose
track_id INTEGER NOT NULL References tracks.id
genre_id INTEGER NOT NULL References genres.id
PRIMARY KEY (track_id, genre_id)

artists

Column Type Purpose
artist_id INTEGER PRIMARY KEY Qobuz artist ID
name TEXT NOT NULL Artist name

album_queue

Column Type Purpose
album_id TEXT PRIMARY KEY Qobuz album ID
artist TEXT Artist name (denormalized)
artist_id INTEGER Qobuz artist ID
title TEXT Album title
