EQ

Parametric EQ (biquad, minimum-phase) and optional linear-phase FIR approximation. Presets live in eq_presets.json; the active global settings are stored in eq_global.json. Each preset may contain a "linear_phase": true|false field (defaults to false).

Route Purpose Files read Files written SQL read SQL written Notes Example
GET /library/eq/presets List available EQ presets eq_presets.json — — — Returns the preset map (keys “00”, “01”, …) curl http://localhost:3000/library/eq/presets
POST /library/eq/apply Apply a preset to the global EQ eq_presets.json eq_global.json — — Body: {"seq":"01"}. Copies the preset (including linear_phase) into the global settings. curl -X POST -H "Content-Type: application/json" -d '{"seq":"01"}' http://localhost:3000/library/eq/apply
GET /library/eq/global Read the current global EQ settings eq_global.json — — — Includes the linear_phase flag curl http://localhost:3000/library/eq/global
POST /library/eq/global Replace the global EQ settings — eq_global.json — — Body is a full EqSettings object (bands + optional linear_phase). When linear_phase is true the FIR path is used at playback; otherwise the biquad path is used. Flat settings short-circuit both paths. curl -X POST -H "Content-Type: application/json" -d @eq_global.json http://localhost:3000/library/eq/global
Linear-phase note: The linear-phase path designs a symmetric FIR that approximates the magnitude response of the configured biquads (using the math-iir-fir crate). It adds latency of roughly half the number of taps (default 1025 → ~512 samples) and is mainly useful when EQ is actually applied. With a flat EQ the result is identical to the minimum-phase path.

Upsampling

Route Purpose Files read Files written SQL read SQL written Notes Example
GET /upsample_track Upsample a single local track Source FLAC under library/ Writes …/{album}/upsampled/{original_filename} and copies tags Looks up track path — Uses UPSAMPLE_BIT_DEPTH (16|24) and UPSAMPLE_SAMPLE_RATE (44100|48000|96000|192000, or short form 44|48|96|192). Skips work if an existing file already matches both settings. Otherwise replaces it. curl "http://localhost:3000/upsample_track?track_id=13176086"
GET /upsample_album Upsample every track of an album All local tracks of the album Upsampled FLACs under the album’s upsampled/ folder + cover.jpg if missing Looks up track paths — Calls the same logic as /upsample_track for each track. Downloads cover into the upsampled folder when absent. curl "http://localhost:3000/upsample_album?album_id=5099749522428"
Upsampling notes
Settings come from the environment (.env):
UPSAMPLE_BIT_DEPTH=24 (16 or 24)
UPSAMPLE_SAMPLE_RATE=96000 (or short form 96)
Files are written next to the originals under an upsampled/ subfolder. An existing file is left untouched when its bit depth and sample rate already match the environment; any other combination is replaced. The first request for a track is CPU-heavy (decode → resample → re-encode). Subsequent matching requests return immediately with status already_upsampled.

Database Tables

  • tracks – path, title, artist, artist_id, album, album_id, track_id, track_number, duration, format, stream_url, genre, dr_score
  • genres – unique genre names
  • track_genres – many-to-many link between tracks and genres
  • artists – artist_id, name
  • album_queue – album_id, artist, artist_id, title (download queue, not playback)

Download layout

Album downloads create this structure under library/:

library/Qobuz/{artist_id} - {artist name}/{year}/{album_id} - {album title}/
    cover.jpg
    01. {track_id} - {title}.flac
    02. {track_id} - {title}.flac
    ...
    upsampled/
        cover.jpg
        01. {track_id} - {title}.flac
        02. {track_id} - {title}.flac
        ...

Existing files are skipped. Tags and front-cover art are embedded with lofty. A dynamic-range score is computed and stored in the tracks table. Upsampled files live in the upsampled/ subfolder and are only rewritten when their bit depth or sample rate differs from the current environment settings.

Environment

Copy .env.example to .env and set at least the Qobuz credentials. Optional upsampling overrides:

UPSAMPLE_BIT_DEPTH=24
UPSAMPLE_SAMPLE_RATE=96000
